## 1. Agent Zero 模型需求分析

Agent Zero 采用**五模型协作架构**，通过功能专门化实现最高效的智能代理。每个模型角色都有明确的职责和性能要求。

```mermaid
graph TD
    A[用户语音/文本] --> B[STT Model: 语音识别]
    B --> C[Chat Model: 智能核心]
    C --> D{工具/模型决策}
    D --> E[Utility Model: 效率助手]
    D --> F[Embedding Model: 记忆引擎]
    D --> G[Browser Model: 网页智能]
    E --> H[任务处理]
    F --> I[语义检索]
    G --> J[网页操作]
    subgraph 响应生成
        H
        I
        J
    end --> K[最终响应]
```

| 模型类型            | 核心职责                                   | 性能关键点                                   | 成本占比 | 调用频率 |
| :------------------ | :----------------------------------------- | :------------------------------------------- | :------- | :------- |
| **Chat Model**      | 复杂推理、任务规划、代码生成、工具调用决策 | **推理能力**、**代码质量**、**工具使用精度** | ~60-70%  | 高       |
| **Utility Model**   | 对话摘要、数据格式化、内部任务处理         | **响应速度**、**成本效益**、**输出稳定性**   | ~20-30%  | 极高     |
| **Embedding Model** | 文本向量化、语义检索 (RAG)                 | **检索精度**、**向量质量**、**多语言支持**   | ~5-10%   | 中       |
| **Browser Model**   | 网页内容理解、视觉元素识别、生成操作指令   | **视觉理解能力**、**操作指令精度**           | ~5-15%   | 低       |
| **STT Model**       | 语音转文字、多语言识别、实时转录           | **识别精度**、**响应速度**、**多语言支持**   | ~0-5%    | 按需     |

## 2. 模型供应平台概览

| 平台           | 核心优势                                                             | 主要限制                                             |
| :------------- | :------------------------------------------------------------------- | :--------------------------------------------------- |
| **Ollama**     | **数据隐私** (完全本地)、**零运营成本**、**离线运行**                | 需要**硬件投入**、模型能力受限于开源水平、需自行维护 |
| **OpenRouter** | **模型统一** (单一 API 访问所有模型)、**灵活切换**、**企业级可靠性** | 价格有**轻微溢价**、新模型上线可能延迟               |
| **Groq**       | **极致速度** (500+ tok/s)、**价格低廉**、**慷慨的免费额度**          | **模型选择有限**、无嵌入和视觉模型                   |

## 3. 三个平台模型解决方案

我们为 Ollama、OpenRouter、Groq 三个平台分别提供经济、推荐、旗舰三层模型配置方案。

### 3.1 Ollama: 本地化部署方案

**核心优势**: 数据隐私、零运营成本、完全控制。适合对数据安全有高要求的用户或离线环境。

**模型选择说明**:

- **qwen2.5:7b**: 相比 qwen2:7b 有显著性能提升，更好的推理能力和中文支持
- **llama3.2:latest**: 通常为 3B 参数的轻量版本，比 llama3:8b 更节省资源但保持良好性能
- **mistral-large:latest**: 替代 command-r-plus，更容易获取且性能相当
- **llama3.2-vision:11b**: 新一代视觉模型，比传统的 llava 模型更高效，支持更复杂的视觉理解任务
- **nomic-embed-text**: 继续作为本地嵌入的最佳选择，稳定可靠

## 5. 实施与切换建议

### 选择路径

1. **新手入门/测试**: 从 **经济方案 (Groq)** 开始。无需配置，注册即用，体验飞快。
2. **个人项目/隐私需求**: 考虑 **经济方案 (Ollama)**。保证数据安全，无运营成本。
3. **正式项目/商业应用**: 直接采用 **推荐方案**。这是大多数场景下的最佳选择。
4. **追求极致性能**: 当推荐方案无法满足需求时，升级到 **旗舰方案**。

### 模型切换须知

- **Chat / Utility / Browser 模型**: 可以随时安全切换，不影响历史数据。
- **Embedding 模型**: **切换成本极高！** 更换嵌入模型意味着所有现存的记忆向量都将失效，需要**清空记忆库并重建所有索引**。请在项目初期谨慎选择，或在切换前做好数据迁移/重建的准备。

通过以上规划，您可以根据自身需求，为 Agent Zero 项目选择最合适的模型配置，并在发展过程中平滑升级。
